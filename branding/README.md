# The Haive brand assets

This directory contains the locked source mark for The Haive and its production derivatives.

- `haive-icon-color.png` — color master
- `haive-icon-adaptive-foreground.png` — adaptive foreground master
- `haive-icon-monochrome.png` — monochrome master

The selected composition is intentionally stable. Platform-specific launcher, favicon, and store assets should be derived from these masters rather than regenerated.
