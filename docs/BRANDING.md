# The Haive branding

The Haive uses the coral/orange node-creature mark selected during the 2026-09-07 branding pass.

## Canonical assets

- `branding/haive-icon-color.png` — color master
- `branding/haive-icon-adaptive-foreground.png` — adaptive/icon foreground master
- `branding/haive-icon-monochrome.png` — monochrome master
- `branding/haive-splash.jpg` — splash/brand presentation asset

Platform-specific launcher and web assets are derived from these masters. The composition should be treated as locked; future changes should be production cleanup or deliberate rebranding rather than generative drift.

## Naming

User-facing product name: **The Haive**

Technical/project shorthand: **Haive** / `haive`
